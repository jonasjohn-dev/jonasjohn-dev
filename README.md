## 👨‍💻 About Me

I'm Jonas John, a Software Engineer based in Dar es Salaam, Tanzania, with a BSc in Computer Science and a passion for building practical software solutions.

I design, develop and maintain web applications, mobile applications, business management systems and multi-tenant SaaS platforms.

My primary development stack is PHP, Laravel and Vue.js. I also work with React Native, REST APIs, PostgreSQL, MySQL, Docker and cloud infrastructure.

I enjoy turning real-world business challenges into scalable software products, building integrations and developing systems that help businesses operate more efficiently.

My interests include:
- SaaS architecture and multi-tenancy.
- Backend engineering and API development.
- ERP and business process automation.
- Fintech and payment integrations.
- E-commerce and digital platforms.
- Cloud infrastructure and DevOps.
- AI-powered applications and automation.
